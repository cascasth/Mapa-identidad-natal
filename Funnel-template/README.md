Esqueleto reusable del funnel de "Archivo de Identidad" (Next.js), sin
contenido ni assets de ningún tema en particular.

Empieza por **`TEMPLATE.md`** — ahí está el mapa completo de pantallas, qué
cambiar para adaptarlo a un tema nuevo, y dónde vive cada pieza de contenido.
Los assets que hay que producir (imágenes, audio, video) están listados en
`public/ASSETS.md`.

```bash
npm install
npm run dev
```
